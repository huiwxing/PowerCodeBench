# results/ — archived result exports

This directory holds result exports from the frozen experimental pipeline,
written with the values formatted as the manuscript quotes them. Look here
to read a reported cell in full, or to find the evidence path behind a
table.

- `full_matrices/` — full per-model matrices (per-difficulty R3, R0-R3 fix
  trajectory, per-task and per-difficulty base-C Round-0); see its README
  for file-by-file provenance.
- `rsemb_budget_sweep.md` — the frozen R_semB budget-calibration
  per-budget sweep record (SM S5, B* calibration protocol).

The raw layers are published alongside these exports in `results/raw/`,
`results/demand_suites/`, and `results/supplementary_evidence/`. The
repository-root `ARTIFACT_INDEX.md` indexes all of them with checksums and
generating scripts. Cited in the supplementary material's
claim-to-evidence index as `results/`.
